Passwort festlegen

Das Passwort selbst wird nirgends gespeichert — nur sein Hash. Diese Seite rechnet ihn direkt hier im Browser aus; es wird nichts verschickt.

Hash (SHA-256)

So einsetzen:
Firebase Console → Realtime Database → beim Knoten samsparking ein Kind gate anlegen, darin pw mit diesem Hash als Wert.

Danach gilt das neue Passwort sofort — alle bisher angemeldeten Geräte müssen sich neu anmelden.
